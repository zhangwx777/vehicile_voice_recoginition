# 车辆声纹识别系统 - 音频分离测试模块

## 项目概述

这个车辆声纹识别系统能够通过分析车辆音频特征来识别不同类型的车辆，并支持音频混合后的特征识别。

## 主要功能

### 1. 车辆声纹识别
- **车辆类型识别**: 识别bus、motorcycle、sedan、suv、truck等不同类型的车辆
- **个体车辆识别**: 识别具体的车辆个体（如bus_000, bus_001等）
- **特征提取**: 使用YAMNet和VGGish深度学习模型提取512维音频特征向量
- **相似度匹配**: 基于余弦相似度进行车辆识别

### 2. 音频混合识别测试
- **随机音频混合**: 随机选择两个车辆的音频文件进行混合
- **特征向量混合**: 直接混合特征向量进行识别测试
- **识别准确率评估**: 评估系统在混合音频情况下的识别性能

## 文件说明

### 核心文件
- `test_database.py` - 数据库功能测试脚本
- `simple_audio_mix_test.py` - 简化版音频混合测试（使用现有特征向量）
- `audio_mix_recognize.py` - 完整音频混合识别测试（需要重新提取特征）

### 数据文件
- `../models/similarity_database.json` - 车辆特征数据库
- `../vehicle_audio_data/` - 原始音频数据目录


```bash
cd separation

```

```bash

```

## 技术特点

1. **深度学习特征提取**: 使用YAMNet和VGGish模型提取高质量音频特征
2. **特征融合**: 结合多个模型的特征进行加权融合
3. **相似度计算**: 基于余弦相似度的向量匹配
4. **音频预处理**: 自动重采样、音量标准化、静音去除
5. **可视化支持**: 生成特征图和识别结果图

## 性能指标

- 相同类型车辆相似度: 通常 > 0.9
- 不同类型车辆相似度: 通常 0.7-0.9
- 混合音频识别准确率: 前5名内识别成功率80-100%
- 处理时间: 单音频处理约3-5秒

## 应用场景

1. **交通监控**: 识别经过的车辆类型
2. **安防系统**: 特定车辆识别和追踪
3. **智能停车**: 车辆进出识别
4. **音频分析研究**: 车辆声纹特征研究

## 注意事项

1. VGGish模型需要下载预训练权重，首次运行可能需要较长时间
2. 确保有足够的存储空间存放音频文件和特征数据库
3. 建议使用GPU加速特征提取过程
4. 音频文件应为WAV格式，采样率16kHz为佳
